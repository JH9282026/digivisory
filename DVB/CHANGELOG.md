# Changelog

All notable changes to the DVB CMS project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-03-12

### Added
- Initial release of DVB CMS self-hosting package
- Complete admin panel with dashboard
- Multiple content editors: WYSIWYG (TipTap), Markdown, HTML, drag-and-drop
- Full SEO features: meta tags, structured data (JSON-LD), XML sitemaps, robots.txt
- AEO/GEO support with llms.txt for AI crawlers
- REST API for all content types
- Import/Export functionality (JSON and WordPress XML)
- Media library with S3 and local storage options
- PostgreSQL database with Prisma ORM
- NextAuth.js authentication with JWT sessions
- Category and tag management
- Custom menu management (header/footer)
- Site settings panel (General, SEO, Theme, Ads, Robots.txt)
- 301/302/410 redirect manager
- 404 error monitoring
- Author profiles with E-E-A-T fields
- Responsive public theme with sidebar
- Docker deployment with Nginx reverse proxy
- Automated installation script
- Backup and restore scripts
- Comprehensive documentation
